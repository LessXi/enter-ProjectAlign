# 服装批发进销存管理系统 — 实施方案

## 背景

场景输入："我们做服装批发，仓库8个人，现在都用Excel记库存，经常出错，上个月盘点差了三万多。想做一个进销存系统——入库出库、库存预警、采购单、对账报表都要有。仓管只看库存，采购能下单。"

## 三、核心用户流程

### 流程 A: 仓管入库操作
```
工作台 → 点击侧栏"入库管理"
  → 点击"新增入库单"
  → 填写: 选商品 → 输入数量/单价/供应商/日期
  → 点击"确认入库"
  → 系统: ① 库存数量增加 ② 生成流水记录 ③ 弹出成功提示
  → 工作台统计卡片实时更新
```

### 流程 B: 采购下单
```
工作台 → 查看"库存预警列表"发现低库存商品
  → 点击侧栏"采购单"
  → 点击"新建采购单"
  → 添加商品行: SKU + 数量 + 预估单价 + 供应商
  → 保存为"草稿" 或 直接"提交"
  → 状态变为"已提交"
```

### 流程 C: 采购到货 → 仓管收货入库
```
采购在"采购单"页面标记"已收货"
  → 仓管在"入库管理"录入对应商品入库
  → 库存更新 → 对账报表自动反映
```

### 流程 D: 月末对账
```
点击"对账报表" → 选择月份
  → 查看: 每个SKU的期初 + 入库 - 出库 = 理论期末
  → 对比实际库存 → 差异列标红
  → 差异 > 0 需核查原因
```

## 五、设计系统

### 色彩
| Token | 值 | 用途 |
|-------|-----|------|
| primary | `230 55% 30%` (深靛蓝) | 主按钮、侧边栏、品牌色 |
| accent/warning | `38 92% 50%` (琥珀橙) | 预警状态、高亮 |
| success | `160 60% 40%` (绿) | 正常状态、入库标识 |
| destructive | `0 72% 51%` (红) | 告急状态、出库、差异 |
| background | `220 20% 97%` | 页面背景 |
| card | `0 0% 100%` | 卡片白底 |
| sidebar-bg | `230 55% 14%` | 侧边栏深色 |

### 排版
- 页面大标题: 24px/600
- 卡片标题: 18px/600
- 表格表头: 14px/600
- 正文: 14px/400
- 辅助文字: 12px/400

### 组件
- **状态标签 Badge**: 正常(绿底绿字) / 预警(琥珀底琥珀字) / 告急(红底红字) / 信息(蓝底蓝字)
- **统计卡片**: 白底圆角8px，左侧彩色图标区，右侧数字+标签
- **数据表格**: 白底圆角，表头灰底加粗，隔行浅色，悬停高亮
- **表单**: 标签+输入框，聚焦蓝色描边+阴影环

## 六、技术实现

### 文件结构
```
src/
├── store/inventoryStore.ts     # Zustand 全局状态 + 种子数据
├── types/inventory.ts          # TS 类型定义
├── components/
│   ├── Layout.tsx              # 侧栏+顶栏+内容区布局
│   ├── AppSidebar.tsx          # 侧边栏导航
│   ├── StatsCard.tsx           # 仪表盘统计卡
│   └── StatusBadge.tsx         # 状态标签组件
├── pages/
│   ├── Index.tsx               # 仪表盘(改写)
│   ├── Inventory.tsx           # 库存管理
│   ├── Inbound.tsx             # 入库管理
│   ├── Outbound.tsx            # 出库管理
│   ├── PurchaseOrders.tsx      # 采购单
│   └── Reports.tsx             # 对账报表
├── index.css                   # 更新设计tokens
├── router.tsx                  # 添加路由
```

### 状态管理 (Zustand)
- `items[]` — 商品SKU列表(含预警阈值)
- `transactions[]` — 入出库流水
- `purchaseOrders[]` — 采购单
- `currentRole` — 'warehouse' | 'purchasing'
- 10个种子SKU + 20条历史流水 + 3张采购单

## 七、验证方式

1. 切换角色 → 菜单项和操作按钮对应变化
2. 入库操作 → 仪表盘数字更新 + 库存页数量增加
3. 库存低于阈值 → 仪表盘预警卡片显示
4. 采购单状态流转: 草稿 → 已提交 → 已收货
5. 对账报表差异列正确计算且红色高亮
