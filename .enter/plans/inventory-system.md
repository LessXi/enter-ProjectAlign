# 服装批发进销存管理系统 — 实施方案

## 背景

场景输入："我们做服装批发，仓库8个人，现在都用Excel记库存，经常出错，上个月盘点差了三万多。想做一个进销存系统——入库出库、库存预警、采购单、对账报表都要有。仓管只看库存，采购能下单。"

---

---

## 二、三种角色定义

| 角色 | 定位 | 核心场景 |
|------|------|---------|
| **仓管** | 执行层 | 每日入库出库录入、查看库存状态 |
| **采购** | 执行层 | 查看库存预警 → 创建采购单 → 跟踪到货 |
| **老板** | 决策层 | 全局经营数据、审批采购单、查看报表、监控差异 |

### 6. 对账报表（多维图表 + 数据表格）

```
┌─────────────────────────────────────────────────────┐
│  月份选择: [2026年3月 ▼]                              │
│                                                     │
│  [进出总览]  [品类分析]  [库存健康]  [差异对账]         │
│  ─────────────────────────────────────────────────── │
└─────────────────────────────────────────────────────┘
```

#### Tab 1: 进出总览
- 柱状图 (BarChart): 最近6月入库(蓝) vs 出库(橙)金额对比
- 折线图 (LineChart): 本月每日入库/出库数量趋势（2条线）
- 底部汇总卡片: 总额、净流入、环比变化率

#### Tab 2: 品类分析
- 饼图 (PieChart): 各品类库存金额占比
- 横向柱状图: Top 5 热销商品(按出库量)
- 品类明细表: SKU数、库存量、金额、占比、周转率

#### Tab 3: 库存健康
- 环形图 (Donut): 正常/预警/告急 SKU分布
- 面积图 (AreaChart): 最近30天库存总量变化
- 预警/告急商品详情表

#### Tab 4: 差异对账
- 正负柱状图: 各商品差异值(正绿/负红)
- 差异对账明细表: 期初+入库-出库=理论期末 vs 实际, 差异行红色高亮

## 四、核心用户流程

### 流程 A: 仓管入库操作
```
工作台 → 侧栏"入库管理" → "新增入库单"
  → 填写商品/数量/单价/供应商/日期 → "确认入库"
  → 系统: 库存+1, 生成流水, 成功提示 → 工作台数据更新
```

### 流程 B: 采购下单 → 老板审批
```
采购: 工作台查看预警 → "采购单" → "新建"
  → 填写商品/数量/单价/供应商 → 保存草稿或提交审批
  → 状态变为"待审批"

老板: 工作台看到"待审批 3" → 点击进入采购单
  → 查看详情 → 点击"批准"或"驳回"
  → 批准后状态变"已批准", 驳回后采购可重新编辑
```

### 流程 C: 采购到货 → 收货入库
```
采购在"采购单"标记"已收货"(仅已批准的单)
  → 仓管在"入库管理"录入对应入库
  → 库存更新 → 报表自动反映
```

### 流程 D: 老板月末经营分析
```
老板: 工作台查看经营概览 → "对账报表"
  → Tab1 进出总览: 月度金额趋势、环比变化
  → Tab2 品类分析: 哪些品类占比大、热销TOP5
  → Tab3 库存健康: 预警告急分布、库存趋势
  → Tab4 差异对账: 发现差异商品 → 安排核查
```

## 七、技术实现

### 文件结构
```
src/
├── store/inventoryStore.ts     # Zustand 全局状态 + 种子数据
├── types/inventory.ts          # TS 类型定义
├── components/
│   ├── Layout.tsx              # 侧栏+顶栏+内容区布局
│   ├── AppSidebar.tsx          # 侧边栏导航(角色感知)
│   ├── StatsCard.tsx           # 仪表盘统计卡
│   └── StatusBadge.tsx         # 状态标签组件
├── pages/
│   ├── Index.tsx               # 仪表盘(角色差异化)
│   ├── Inventory.tsx           # 库存管理
│   ├── Inbound.tsx             # 入库管理
│   ├── Outbound.tsx            # 出库管理
│   ├── PurchaseOrders.tsx      # 采购单(含审批)
│   └── Reports.tsx             # 对账报表(多维图表)
├── index.css                   # 更新设计tokens
├── router.tsx                  # 添加路由
```

### 状态管理 (Zustand)
- `items[]` — 商品SKU列表(含品类、预警阈值)
- `transactions[]` — 入出库流水(含日期、金额)
- `purchaseOrders[]` — 采购单(含审批状态)
- `currentRole` — 'warehouse' | 'purchasing' | 'boss'
- 10个种子SKU + 60条历史流水(3个月) + 5张采购单(含各种状态)

## 八、验证方式

1. 切换3种角色 → 菜单项、操作按钮、仪表盘内容对应变化
2. 老板仪表盘显示增强版(库存总值、待审批数、迷你趋势图)
3. 采购提交采购单 → 老板视角出现审批按钮 → 批准/驳回生效
4. 老板视角无入库/出库菜单
5. 入库操作 → 仪表盘数字更新 + 库存页数量增加
6. 对账报表 4 个 Tab 图表均正确渲染
7. 差异对账表差异列正确计算且红色高亮
