# 服装批发进销存管理系统 — 实施方案

## Context

基于图片场景输入："我们做服装批发，仓库8个人，现在都用Excel记库存，经常出错，上个月盘点差了三万多。想做一个进销存系统——入库出库、库存预警、采购单、对账报表都要有。仓管只看库存，采购能下单。"

构建一个有逻辑、有美感的前端演示系统，使用 React + Tailwind 实现，带内存种子数据（用于演示）。

---

## 系统架构

### 路由 & 页面
| 路由 | 页面 | 角色权限 |
|------|------|---------|
| `/` | 仪表盘 Dashboard | 全部 |
| `/inventory` | 库存管理 | 全部（采购可编辑） |
| `/inbound` | 入库管理 | 仓管 + 采购 |
| `/outbound` | 出库管理 | 仓管 + 采购 |
| `/purchase-orders` | 采购单 | 采购（仓管只读） |
| `/reports` | 对账报表 | 全部 |

### 角色切换
顶部 / 侧边栏提供角色切换：**仓管视角** / **采购视角**，影响可见操作按钮和菜单项。

## 状态管理

使用 **Zustand**（已在 package.json 中）管理：
- `items[]` — 商品库存列表（含预警阈值）
- `transactions[]` — 入出库流水
- `purchaseOrders[]` — 采购单
- `currentRole` — 'warehouse' | 'purchasing'
- actions: `addInbound`, `addOutbound`, `createPO`, `updatePOStatus`

约 20 条历史交易流水，3 张采购单（待确认 / 进行中 / 完成）。

## 核心功能点

### 仪表盘
- 4 个统计卡片：总 SKU 数、库存预警数、本月入库金额、本月出库金额
- 预警商品列表（库存 < 阈值）
- 最近 5 条流水记录

### 库存页
- 表格展示：SKU、品名、规格、库存量、预警阈值、状态标签（正常/预警/告急）
- 搜索 + 状态筛选

### 入库 / 出库页
- 表单：选商品、数量、单价、备注、日期
- 提交后更新库存，记录流水
- 历史列表

### 采购单页（采购角色）
- 新建采购单：选商品、数量、预计到货日期
- 状态流转：草稿 → 已提交 → 已收货
- 仓管视角只读查看

### 对账报表
- 按月汇总：期初库存、入库、出库、期末库存、差异值
- 以表格 + 差异高亮展示（差异 > 0 红色标注）

---

## 验证方式

1. 切换角色（仓管/采购）确认菜单和按钮权限变化
2. 入库操作后，仪表盘统计数字更新、库存页数量增加
3. 库存降至阈值以下时，仪表盘预警卡片显示
4. 采购单状态流转正常
5. 对账报表数据与流水对应
