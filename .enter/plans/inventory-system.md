# 服装批发进销存管理系统 — 实施方案

## 背景

场景输入："我们做服装批发，仓库8个人，现在都用Excel记库存，经常出错，上个月盘点差了三万多。想做一个进销存系统——入库出库、库存预警、采购单、对账报表都要有。仓管只看库存，采购能下单。"

## 三、核心用户流程

### 流程 A: 仓管入库操作
```
工作台 → 点击侧栏"入库管理"
  → 点击"新增入库单"
  → 填写: 选商品 → 输入数量/单价/供应商/日期
  → 点击"确认入库"
  → 系统: ① 库存数量增加 ② 生成流水记录 ③ 弹出成功提示
  → 工作台统计卡片实时更新
```

### 流程 B: 采购下单
```
工作台 → 查看"库存预警列表"发现低库存商品
  → 点击侧栏"采购单"
  → 点击"新建采购单"
  → 添加商品行: SKU + 数量 + 预估单价 + 供应商
  → 保存为"草稿" 或 直接"提交"
  → 状态变为"已提交"
```

### 流程 C: 采购到货 → 仓管收货入库
```
采购在"采购单"页面标记"已收货"
  → 仓管在"入库管理"录入对应商品入库
  → 库存更新 → 对账报表自动反映
```

### 流程 D: 月末对账
```
点击"对账报表" → 选择月份
  → Tab1 进出总览: 查看月度进出金额对比 + 每日趋势
  → Tab2 品类分析: 查看哪些品类占比最大、哪些最热销
  → Tab3 库存健康: 查看预警/告急分布 + 库存趋势
  → Tab4 差异对账: 核对每个SKU的进出差异，红色标记异常
```

```

├── pages/
│   ├── Index.tsx               # 仪表盘(改写)
│   ├── Inventory.tsx           # 库存管理
│   ├── Inbound.tsx             # 入库管理
│   ├── Outbound.tsx            # 出库管理
│   ├── PurchaseOrders.tsx      # 采购单
│   └── Reports.tsx             # 对账报表(多维图表)
├── index.css                   # 更新设计tokens
├── router.tsx                  # 添加路由
```

### 图表技术
- 使用 Recharts (shadcn chart 组件底层)
- BarChart: 月度进出对比 + 差异分布
- LineChart: 每日趋势
- AreaChart: 库存总量变化
- PieChart: 品类占比 + 库存健康环形图
- 响应式 ResponsiveContainer

### 状态管理 (Zustand)
- `items[]` — 商品SKU列表(含品类、预警阈值)
- `transactions[]` — 入出库流水(含日期、金额)
- `purchaseOrders[]` — 采购单
- `currentRole` — 'warehouse' | 'purchasing'
- 10个种子SKU + 60条历史流水(3个月) + 3张采购单

## 七、验证方式

1. 切换角色 → 菜单项和操作按钮对应变化
2. 入库操作 → 仪表盘数字更新 + 库存页数量增加

5. 对账报表 4 个 Tab 图表均正确渲染，数据与流水对应
6. 图表 hover 显示 Tooltip，数据准确
7. 差异对账表差异列正确计算且红色高亮
