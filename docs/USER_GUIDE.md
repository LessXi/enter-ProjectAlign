# 用户操作指导 — 衣仓管家

## 1. 登录系统

1. 打开系统，进入登录页面
2. 在「姓名或邮箱」输入框中输入您的姓名或邮箱
3. 输入密码，点击「登录」

> 所有账号由管理员（老板）在「员工管理」中统一创建，如需开通请联系管理员。

---

## 2. 工作台

登录后默认进入工作台，展示系统核心数据概览：

- **统计卡片**：总 SKU 数、预警商品数、本月入库额（紫色）、本月出库额（绿色）
- **趋势图**：本月按周汇总进出金额柱状图 + 利润折线（金色，右侧 Y 轴）
- **库存预警表**：列出低于阈值的商品，采购角色可点击「采购」按钮快速补货
- **最近流水**：最近 20 条出入库记录，显示商品名、对手方、数量和金额

老板额外可见：库存总值、待审批采购单列表。

---

## 3. 库存管理

查看所有商品的库存情况：

1. 点击侧边栏「库存管理」
2. 使用搜索框按品名、SKU 或规格搜索
3. 使用下拉框按状态筛选（全部/正常/预警/告急）

状态说明：
- **正常**（绿色）：库存充足
- **预警**（黄色）：库存低于预警阈值
- **告急**（红色）：库存低于阈值的 30%

---

## 4. 入库登记（仓管/老板）

记录商品入库：

1. 点击侧边栏「入库登记」
2. 点击右上角「新增入库单」
3. 填写表单：
   - 选择商品（单价会自动填入）
   - 输入数量
   - 输入/确认单价
   - 输入供应商名称
   - 选择日期（默认今天）
   - 可选：添加备注
4. 点击「确认入库」

入库成功后库存自动增加，下方历史列表实时更新。

---

## 5. 出库登记（仓管/老板）

记录商品出库：

1. 点击侧边栏「出库登记」
2. 点击右上角「新增出库单」
3. 填写表单（与入库类似，「供应商」替换为「客户」）
4. 点击「确认出库」

出库成功后库存自动减少。

---

## 6. 采购单管理

### 采购角色 — 创建采购单

1. 点击侧边栏「采购单」
2. 点击「新建采购单」（或从工作台预警表点击「采购」自动预填）
3. 选择商品方式：
   - **选择已有商品**：从下拉列表选取
   - **新增商品**：填写商品名、品类、规格，SKU 自动生成
4. 填写数量、预估单价、供应商、备注
4. 选择操作：
   - 「保存草稿」：暂存，稍后提交
   - 「提交审批」：发送给老板审批

### 采购角色 — 后续操作

| 采购单状态 | 可执行操作 |
|------------|-----------|
| 草稿 | 提交审批 |
| 已批准 | **收货**（自动入库，库存增加） |
| 已驳回 | 重新编辑（退回草稿） |

> 点击「收货」后，系统自动为采购单中每件商品创建入库记录并更新库存。

### 老板 — 审批采购单

1. 在采购单列表或工作台待审批区域找到待审批单据
2. 点击绿色勾号「批准」或红色叉号「驳回」

### 查看采购单详情

点击任意采购单的眼睛图标，展开详情面板查看商品明细、金额、供应商等信息。

---

## 7. 对账报表

综合分析系统数据：

### 时间段选择
页面顶部提供快捷时间段：今日、本周、本月（默认）、本季度、本年、自定义。

### 四个分析维度

#### 进出总览
- 进出金额对比柱状图（短期按日、长期按月自动切换）
- 利润趋势面积图（金色渐变）
- 汇总卡片：入库总额、出库总额、利润（金色）、交易笔数

#### 品类分析
- 库存金额品类占比饼图
- Top 5 热销商品排行
- 品类明细表

#### 库存健康
- 库存状态分布饼图（正常/预警/告急）
- 库存总量变化趋势面积图
- 预警/告急商品清单

#### 差异对账
- 差异值分布图
- 完整对账明细表：期初库存 → 入库 → 出库 → 理论期末 → 实际库存 → 差异

---

## 8. 员工管理（仅老板）

管理系统用户账号：

### 创建员工
1. 点击「创建账号」
2. 填写姓名、邮箱、密码、角色（仓管/采购/老板）
3. 点击「创建账号」
4. 创建成功后可在列表中复制账号信息发给员工

### 编辑员工
- 点击铅笔图标修改姓名、邮箱、密码、角色
- 修改自己的密码后会自动退出登录

### 删除员工
- 点击垃圾桶图标，确认后删除（不可删除自己）

### 查看/复制密码
- 点击眼睛图标显示/隐藏密码
- 点击复制图标一键复制完整账号信息（姓名、邮箱、密码、角色）

---

## 颜色含义速查

| 颜色 | 含义 |
|------|------|
| 紫色 (Lavender) | 入库 / 采购支出 |
| 绿色 (Mint) | 出库 / 销售收入 |
| 琥珀色 (Amber) | 预警提醒 |
| 红色 | 告急 / 错误 / 删除 |
| 深色 (#1A1A2E) | 强调信息（按钮、特殊卡片） |
